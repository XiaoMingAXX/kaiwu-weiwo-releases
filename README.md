# 开物·帷幄驾驶舱客户端：下载

这里是远程驾驶挖掘机用的电脑客户端的下载页，只放安装包和使用说明。

## 怎么下载

1. 打开 [所有版本](../../releases)，最新的在最上面。标着 "Pre-release" 的是**测试版**，只在维护者安排的测试里用。
2. 每个版本下面都写着"这一版有什么变化"。往下翻到附件（Assets），按你的电脑下载：

| 你的电脑 | 下载这个 |
| --- | --- |
| Windows 10 / 11 | 名字里带 `windows` 的 `.exe` 安装包，和 `field-guide-windows.html` |
| Ubuntu 22.04 / 24.04 | 名字里带 `linux` 的 `.deb` 安装包，和 `field-guide-linux.html` |

**第一次用，请先看使用说明**（`field-guide-….html`）：怎么安装、怎么连上挖掘机、怎么停下，出了问题找谁，都写在里面。它是网页文件，下载后双击就能用浏览器打开。

## 安装前先核对文件

核对一下，确认文件下载完整、没被改过。把安装包和同一版本的 `SHA256SUMS` 放在同一个文件夹里：

- **Ubuntu**：在这个文件夹里打开终端，运行 `sha256sum -c --ignore-missing SHA256SUMS`，看到"成功"或 "OK" 就对了。
- **Windows**：在这个文件夹里打开 PowerShell，运行 `Get-FileHash 安装包的文件名`，把显示出来的一长串字符，和 `SHA256SUMS` 里同名那一行对一下。

对不上就不要安装，联系维护者。

## 安全须知

- **安装包里没有任何密码和机器地址。** 连接用的接入包由维护者单独给你，不要转发给别人，也不要传到网上。
- **驾驶舱里的"软件停止"不是急停。** 真正的急停在现场监护人手里，不经过网络和这台电脑。
