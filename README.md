# 开物·帷幄驾驶舱客户端：发布版下载

这里只放驾驶舱客户端的**安装包**和**现场使用说明**，不放源代码。每个版本是一个 Release。

## 下载

打开 [Releases](../../releases)，最新版在最上面。每个版本附带：

| 文件 | 用途 |
| --- | --- |
| `kaiwu-weiwo_<版本>_windows_x64-setup.exe` | Windows 10 / 11 安装包（按当前用户安装，不需要管理员） |
| `kaiwu-weiwo_<版本>_linux_amd64.deb` | Ubuntu 22.04 / 24.04 安装包 |
| `field-guide-windows.html`、`field-guide-linux.html` | 现场使用说明，下载后双击用浏览器打开 |
| `SHA256SUMS` | 安装包的校验和 |
| `RELEASE_NOTES.md` | 这个版本改了什么 |

带 "Pre-release" 标记的是预发布版，只用于测试。

**第一次使用请先读对应系统的现场使用说明**：怎么核对下载的文件、安装、连接、停止，以及出了问题找谁。

## 核对下载的文件

把安装包和 `SHA256SUMS` 放在同一个文件夹里：

- Linux：在这个文件夹里运行 `sha256sum -c --ignore-missing SHA256SUMS`，显示"成功"或 "OK" 即可。
- Windows：在 PowerShell 里运行 `Get-FileHash <安装包文件名>`，把显示的值和 `SHA256SUMS` 里同名那一行对一下。

对不上就不要安装，联系维护者。

## 安全

- 安装包里**没有**任何连接密钥和机器地址。连接用的配置由维护者另外提供，不要转发给别人，也不要传到网上。
- 驾驶舱里的"软件停止"不是急停。真正的停机手段是现场监护人手里的无线急停，它不经过网络和这台电脑。

## 反馈

这个仓库不处理问题反馈。使用中遇到问题，请联系维护者，并附上截图、发生时间和客户端版本号。
